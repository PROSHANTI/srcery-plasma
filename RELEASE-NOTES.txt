SRCERY Plasma 1.2.0
Community adaptation by SHANTI.

One self-contained Plasma/LookAndFeel package with zero external KNS dependencies.
Install and update from KDE System Settings / Global Theme / Get New.
No terminal commands, separate installer or administrator privileges are required.

Contains exact Srcery colors, previews, animated logo splash and grey logo wallpaper.
Uses the Breeze components included with KDE. Existing icons, wallpaper/slideshow,
panels and widgets are preserved. Iosevka is requested if already available;
Qt selects an available font fallback automatically otherwise. No font is installed.

Verified on Steam Deck / Plasma 6.7.3:
- Clean installation and custom XDG paths.
- Direct native upgrades from original 1.0.0 and native 1.1.0.
- Recovery after an interrupted upgrade.
- Actual Plasma control colors: #1C1B19 background, #FCE8C3 text.
- Gold selection, embedded wallpaper resolution, icon and slideshow preservation.
- Reproducible release archive and matching published SHA256.
