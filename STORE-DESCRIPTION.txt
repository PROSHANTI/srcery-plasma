SRCERY Plasma 1.2.0 by SHANTI

One self-contained KDE Plasma 6 Global Theme. Charcoal backgrounds, parchment
text, gold highlights, native Breeze appearance, animated logo splash and
embedded grey logo wallpaper. No companion downloads or separate installer.

Install or update through System Settings / Colors & Themes / Global Theme /
Get New. Search SRCERY Plasma, click Install or Update, then select and Apply.
Existing icons, wallpaper/slideshow, panels and widgets are preserved.
Iosevka is used if already available; otherwise Qt chooses a font fallback.

Direct upgrades from 1.0.0 and 1.1.0 are verified. The old separate style is no
longer updated, so its missing package-type metadata cannot block installation.
